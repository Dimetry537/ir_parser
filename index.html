🖨️ Парсер тестов Infourok

Как пользоваться:
1. Откройте тест на Infourok, нажмите F12.
2. Во вкладке Elements найдите <div class="document-content__text">.
3. Нажмите ПКМ -> Copy -> Copy outerHTML.
4. Вставьте код в поле ниже и нажмите "Обработать".
5. Для сохранения в PDF: нажмите "Распечатать" -> выберите "Сохранить как PDF".
