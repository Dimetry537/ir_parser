🖨️ Очистка тестов Infourok

Как пользоваться:
1. Откройте нужный тест на Infourok.
2. Нажмите F12 (или ПКМ -> "Просмотреть код").
3. Найдите элемент с классом document-content__text (или просто выделите весь код страницы через Ctrl+A в окне кода).
4. Нажмите ПКМ на элементе -> Copy -> Copy outerHTML.
5. Вставьте код в поле ниже и нажмите "Обработать".

Здесь появится очищенный тест, готовый к печати...
